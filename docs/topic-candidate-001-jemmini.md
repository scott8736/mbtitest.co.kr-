## 기회 (O)

- 빈 SERP 신호 0.95 — 위 붕괴 근거
- 질문형 수요 0.70 — "뜻", "정체는?", "아세요?" 형태로 검색 의도가 명확
- 자사 적합도 1.00 — 성격 유형 신조어 + 심리 테스트, `egen-teto`와 동일 패턴

## 점수 계산

```
D = 0.5(0.50) + 0.3(0.35) + 0.2(0.80) = 0.515
C = 0.4(0.375) + 0.3(0.40) + 0.2(0.00) + 0.1(0.25) = 0.295
O = 0.5(0.95) + 0.3(0.70) + 0.2(1.00) = 0.885

SCORE = (0.515^1.2 × (1-0.295) × (0.5+0.885)) × 100 = 44.0
```

경쟁(C=0.295)과 기회(O=0.885)는 최상급인데 **수요(D=0.515)가 발목을 잡는다.**
롱테일 신조어라 절대 검색량이 작다. Google Trends·DataLab 실측이 붙으면
D가 올라가 55를 넘길 가능성이 있으므로, 소스 연동 후 재평가 대상.

> 이 컨테이너의 egress 프록시가 trends.google.co.kr, 네이버·연합뉴스,
> signal.bz를 모두 차단해 상승률·검색량은 **실측하지 못했다.** D는 보수적 추정치다.
